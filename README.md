**Adventurer Expedition Game**

A JavaFX guild management game built for SENG201 at the University of Canterbury.
Hire adventurers, buy upgrades, and send your party on expeditions to collect loot and gold.
By William Condon(ID: 11583704) and Allistair Clarke().

Requirements: Java 17+

1. Clone and build:

bashgit clone https://eng-git.canterbury.ac.nz/[your-group-path]/seng201-project.git
cd seng201-project
./gradlew jar


2. Run:

bashjava -jar build/libs/AdventurerResourceCollector.jar

Run in IntelliJ:
 File → Open → select project folder, set SDK to Java 17, then run App.java.


Tests:
bash./gradlew test
