**Adventurer Expedition Game**

A JavaFX guild management game built for SENG201 at the University of Canterbury.
Hire adventurers, buy items, and send your party on expeditions to collect loot and gold.
By William Condon (ID: 11583704) and Alistair Clarke (ID: 64289867).

Requirements: Java 17+

1. Clone and build:

```bash
git clone https://eng-git.canterbury.ac.nz/seng201-2026/team-66.git
cd team-66
./gradlew jar
```

2. Run:

```bash
java -jar build/libs/AdventurerResourceCollector.jar
```

Run in IntelliJ: File → Open → select project folder, set SDK to Java 17, then run App.java.

Tests:

```bash
./gradlew test
```
